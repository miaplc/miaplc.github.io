The examples on a real board, with MiaConfig

Take an ESP32 that costs a few euros, wire buttons and LEDs on a breadboard and load the same examples as in the simulator. One configuration works for Motor start / stop, Traffic light and the relay song.

The firmware is the software that runs on the board and turns it into a PLC. MiaConfig is the PC program that prepares and loads it. This is the advanced road, for those starting from any development board: no MIAplc board with the firmware already inside is in circulation yet. Development boards are fine for learning and testing; commercial use needs CE-marked boards: see Compliance.

What you need

To skip steps 2 to 6, download the ready-made project esp32-devkit-esempi.mia and open it in MiaConfig with Apri progetto (open project).

1 · Start MiaConfig

🚧 coming MiaConfig downloads are not available yet: they arrive in early 2027, together with the code on GitHub. On Windows double click avvia.bat: the first time it prepares its own Python (internet needed), then opens the window. On Linux and macOS follow the README. Nothing is installed in the system: everything stays in its folder.

2 · New project

On the Nuovo progetto (new project) page keep PLC, type a name, choose the family ESP32 (classico) and the module ESP32-WROOM-32E / 32UE. Crea (create).

The project already has the serial port for the editor (GPIO 1 and 3), WiFi, digital inputs and outputs. On the left the list of modules, in the middle the chip with its pins, on the right the settings of the chosen module.

If MiaConfig asks for the administrator password, choose one: at least 10 characters, with an uppercase letter, a lowercase letter, a number and a special character. You will need it to log in to the board's editor. MiaConfig creates the board's other passwords by itself.

3 · Digital inputs

Click Ingressi digitali (digital inputs) on the left and set Ingressi = 3. MiaConfig picks free, suitable pins (GPIO, the chip's pins) by itself: I0 → GPIO34, I1 → GPIO35, I2 → GPIO36. In the Commento (comment) column write what they are for: you will find them in the pinout and in the editor's point table.

To change a pin choose another GPIO from the list: unsuitable ones (flash, boot, already used) are flagged.

4 · Digital outputs

Uscite digitali (digital outputs) → Uscite = 3: Q0 → GPIO16, Q1 → GPIO17, Q2 → GPIO18.

5 · WiFi

With WiFi the board creates its own network (it acts as an access point): the PC connects straight to it, no router needed. Keep the defaults.

SettingDefault
Nome rete (network name)miaplc-XXXX (the last digits come from the chip)
Passwordrandom and different for every board: MiaConfig creates it. You see it in «Accesso alle schede…» (Board access…) → «Mostra» (Show), WPA2 access point column
PLC IP10.10.10.1

6 · Check

Mappa I/O (I/O map) sums up inputs and outputs with their pins. At the top the counters gravi / avvisi / info (errors / warnings / info) must show 0 gravi: with an error the firmware does not build, and Controlli (checks) says what to fix. Salva (save) to keep the project (.mia).

7 · Build and load

Connect the board to the PC with the USB cable and open Genera (generate).

  1. Press ↻ Cerca (search) and choose the board's port (COMx on Windows, /dev/ttyUSB0 on Linux).
  2. Press Carica (load): MiaConfig builds the firmware and writes it to the board. The first time it downloads ESP-IDF, the compilers and the MIAplc firmware: it takes a while, later only a few minutes.

Loading over USB erases the PLC's program, settings and files: fine on a new board. To update a PLC already in use, pick its «rete» (network) entry in the port list: program and settings are kept.
Alternatively: Compila firmware (build firmware) creates the .miaplc.fw package in uscita/, which you load from the editor (Connection → Firmware).

8 · Wiring

Unplug the USB cable before wiring. The ESP32 works at 3.3 V: never 5 V on its pins.

SignalPinConnection
I0 Start / EnableGPIO34button between 3V3 and the pin; 10 kΩ resistor between the pin and GND
I1 StopGPIO35
I2 OverloadGPIO36 (often labelled «VP» or «SVP» on the board)
Q0 Motor / GreenGPIO16pin → 330 Ω resistor → LED (long leg) → LED (short leg) → GND
Q1 Lamp / YellowGPIO17
Q2 Alarm / RedGPIO18
  • Why the 10 kΩ resistor: GPIO34, 35 and 36 are input-only and have no internal resistor. Without it, with the button open the pin «floats» and the PLC reads random 0s and 1s. With the resistor to GND it reads 0 at rest and 1 when pressed.
  • Relays: for the relay song use a relay module with a 3.3 V input on Q0 (GPIO16) and Q1 (GPIO17), powered as its datasheet says. Never a relay coil straight on a pin. Many modules switch on with the pin at 0 («active low» input): then the relays do the opposite of the LEDs.
  • Stop in real plants: here Stop is a normally open button, as in the simulator. On a real machine the stop is wired normally closed, so a broken wire stops the motor, and in the ladder it becomes an NO contact. Remember also that MIAplc is not a safety device: the real emergency stop goes through safety circuits and components.

9 · Open the board's editor

  1. Plug the USB cable back in (or a USB power supply): the board starts.
  2. From the PC connect to the WiFi network miaplc-XXXX with the board's WPA2 password (in MiaConfig: «Accesso alle schede…» (Board access…) → «Mostra» (Show)).
  3. In the browser open http://10.10.10.1: it is the same editor as the simulator, but now it talks to the real board.
  4. Log in with the administrator password you chose in MiaConfig.

Open 🩺 Diagnostics to check everything is fine: PLC status, versions, event log and cycle times.

10 · Load the example

  1. Download the example file: motor-start-stop, traffic-light or canzoncina. Or use the project you built with the first manual and saved with 💾 Save.
  2. In the board's editor: 📂 Open and choose the file.
  3. Download to cpu, confirm, then RUN.
  4. Online and test with the real buttons: Start lights the green LED (Q0), after 3 s the yellow one (Q1); Stop switches it off.
ExampleInputs usedOutputs used
Motor start / stopI0 Start, I1 Stop, I2 OverloadQ0 Motor, Q1 Lamp, Q2 Alarm
Traffic lightI0 EnableQ0 Green, Q1 Yellow, Q2 Red
The relay songI0 from the topQ0 and Q1 (relays)

The program stays in the board's memory: at the next power-up it starts by itself.

If something goes wrong

ProblemWhat to check
MiaConfig does not see the portUSB data cable; driver of the board's USB converter (CP210x or CH340); another program keeping the port open
Loading does not startsome boards need the BOOT button held at the start of the load
I can't find the miaplc-XXXX networkis the board powered? After loading press EN (reset) once
An input changes by itselfthe 10 kΩ resistor to GND is missing
An LED does not light upLED the wrong way round (long leg towards the pin) or missing resistor; Online, check whether the coil is green
Download says «not connected to any GPIO»the program uses an input or output you did not create in MiaConfig: raise the count and load the firmware again
